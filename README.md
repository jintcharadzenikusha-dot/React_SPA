# VELA — სტუდენტი 2

ეს არის სტუდენტი 2-ის **რეალურად გამოყოფილი** React აპლიკაცია.

მიმართულება: კალათა, Redux-ის მოქმედებები, checkout Formik/Yup და შეკვეთა

საიტი იყენებს საერთო VELA CSS დიზაინის სისტემას, მაგრამ არ შეიცავს სხვა სტუდენტების მოდულებს. ინდივიდუალური ეტაპის ჩვენება შესაძლებელია დამოუკიდებლად.

გაშვება: `npm install`, `npm run dev`; შემოწმება: `npm run build`.

**შენიშვნა:** სტუდენტი 2-ის პროდუქტის მარტივი სია მხოლოდ კალათის დემონსტრირების *მონაცემთა წყაროა* და არ შეიცავს სტუდენტი 1-ის პროდუქტის მართვის მოდულს.

ავტორიზაცია დემოა, არ გამოიყენოთ ნამდვილი პაროლები. გადახდები რეალურად არ მუშავდება.
